# A Little World Made for You 🌷
Static birthday website (no build step).

## Files
- index.html : the whole site (edit CONFIG in the script for names, captions, notes, password)
- audio/what-jhumka.mp3 : music (plays after the welcome celebration)
- images/ : add mahi.jpg and memory-01.jpg ... memory-08.jpg

## Deploy on GitHub Pages
1. Push everything to a GitHub repo (index.html must be in the repo root).
2. Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
3. Open https://YOUR-USERNAME.github.io/REPO-NAME/

Netlify / Vercel: drag the folder in, no settings needed.
